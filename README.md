# backup-restore-cli

macOS環境において、外付けSSDへ日付ごとのスナップショットバックアップを作成し、新しいMacや環境復旧時に安全にリストア（復元）するためのCLIツールセットです。

## 背景・目的

日常的なデータ保護やMacの買い替え・環境移行の際、手動でのコピー作業による「コピー漏れ」「誤ったディレクトリへの上書き」「SSDのアンマウント忘れ」といったヒューマンエラーをなくすために開発しました。

## 主な機能

* **日付別スナップショット作成 (`backuptool.sh`)**: `YYYY_MM_DD` 形式で世代管理しながら `rsync` による差分・高速バックアップを実行します。
* **リアルタイム進捗バー**: バックアップ対象のファイル数を事前計算し、ディレクトリごとに進捗バーとパーセンテージを表示します。
* **インタラクティブな復元 (`restoretool.sh`)**: SSD内の最新バックアップを自動検出し、任意の日付を指定してホームディレクトリへ復元できます。
* **自動アンマウント**: バックアップ・復元完了後に `diskutil eject` を自動実行し、安全なSSDの取り外しまでを完結させます。

## ディレクトリ構成

```text
backup-restore-cli/
├── README.md
├── install.sh          # 実行権限の付与とPATH設定を行うセットアップスクリプト
└── bin/
    ├── backuptool.sh      # 外付けSSDへのバックアップ実行スクリプト
    └── restoretool.sh     # 外付けSSDからの復元実行スクリプト
```

## 動作環境

* macOS（`diskutil`, `rsync`, `/usr/bin/perl` を使用）
* Zsh / Bash

## セットアップ（インストール）

1. リポジトリをクローンします。
   ```bash
   git clone https://github.com/okayan22/backup-restore-cli.git
   cd backup-restore-cli
   ```

2. セットアップスクリプトを実行し、PATHを通します。
   ```bash
   chmod 755 install.sh
   ./install.sh
   source ~/.zshrc
   ```

## 使い方

### 1. 事前設定
`bin/backuptool` 内の変数をお使いの環境に合わせて編集します。
* `SSD_NAME`: 使用する外付けSSDのボリューム名（デフォルト: `PortableSSD`）
* `SOURCES`: バックアップ対象のディレクトリ・ファイルパス

### 2. バックアップの実行
外付けSSDをMacに接続した状態で以下を実行します。
```bash
backuptool.sh
```
実行すると項目ごとの進捗バーが表示され、完了後にSSDが自動的に取り出されます。

### 3. データの復元（リストア）
```bash
restoretool.sh
```
1. SSD内の最新バックアップ日付が自動表示されます（Enterで最新を選択、または `YYYY_MM_DD` 形式で日付を指定）。
2. 復元対象の一覧を確認後、誤操作防止のためプロンプトに `RESTORE` と入力すると復元が開始されます。

## 設計上の工夫・こだわった点

* **マウントポイントの厳密な検証（誤書き込み防止）**
  単に `/Volumes/<SSD_NAME>` ディレクトリが存在するかどうかだけでなく、`diskutil info` の出力を検証することで、SSD未接続時にローカルの `/Volumes` 配下へ誤ってデータを書き込んでしまう事故を防いでいます。
* **フェイルファスト設計 (`set -euo pipefail`)**
  未定義変数の参照やパイプライン途中のエラーを即座に検知して処理を中断させることで、不完全な状態での処理続行を防止しています。
* **視認性の高いプログレス表示**
  `rsync` の出力を Perl スクリプトへパイプしてリアルタイムに集計することで、標準の `rsync` だけでは把握しづらい「ディレクトリ全体の完了率」をプログレスバーで可視化しました。
* **誤上書き防止の2段階確認と環境変数対応**
  `restoretool` では既存ファイルの上書きリスクを考慮し、`RESTORE` という明示的なキーワード入力を必須としました。また、`SSD_NAME=MySSD restoretool` のように実行時の環境変数でSSD名を柔軟に切り替えられる設計にしています。
